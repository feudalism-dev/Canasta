CANASTA / HAND & FOOT — SCOREBOARD QUICK START
=============================================
Thank you for your purchase. This notecard covers how to rez and use the parlor Scoreboard in Second Life. It does not teach card rules.

The Scoreboard is a separate wall panel. It hears finished games from a nearby Canasta / Hand & Foot table, stores high scores, and shows them on a media screen. The game table is sold separately.


1) WHAT IT DOES
---------------
- Records each seated human player's team score when a match ends (not after every hand).
- Computer players are skipped.
- Keeps the top 10 scores per board. If you already have an entry, only a higher score replaces it.
- Canasta and Hand & Foot are tracked separately (different score scales).
- Samba and Bolivia tabs are on the screen as Coming soon (beta — scores are not recorded yet).

Boards you can view on the screen:

- This parlor — Weekly / Monthly / Lifetime (stored on this scoreboard object)
- Network — Weekly / Monthly / Lifetime (shared across scoreboards that use the same Experience)


2) WHAT YOU NEED
----------------
- This Scoreboard object (do not unlink the frame, screen, and gear).
- A Canasta / Hand & Foot game table within about 100 meters (shout range). The table must include the scores shout script that comes with the table product.
- Parcel must allow the Debauchery RPG Experience (required for Network boards; local parlor boards still work without Network).
- Enable Media in your viewer. Whitelist this domain on the parcel if your estate requires media allow-lists:

    feudalism-dev.github.io


3) REZZING THE SCOREBOARD
-------------------------
1. Rez the Scoreboard from inventory near your table (same region, within 100 m).
2. Keep it as one linked set. Do not unlink the parts.
3. Point the screen toward where players and guests look.
4. Wait a few seconds for media to load. Touch is for the gear only — guests read the screen; they do not need to click it to see scores.

Prim roles (already set in the product):

- Frame (root) — main scoreboard script
- Screen (named "screen") — media display
- Gear — owner / admin menus


4) USING THE SCREEN
-------------------
On the media page, use the tabs to pick:

- Game: Canasta, Hand & Foot, Samba, or Bolivia (Samba and Bolivia say Coming soon)
- Scope: This parlor or Network
- Period: Weekly, Monthly, or Lifetime

Spectators only need to look at the screen. Network tallies refresh on their own every few seconds when Experience is allowed.


5) HOW SCORES GET RECORDED
--------------------------
When a match at a nearby table finishes, the table shouts one score line per seated human. The Scoreboard listens on a private channel and updates the boards.

Place the Scoreboard close enough to hear the table (about 100 m). Multiple tables in range can feed the same parlor board.


6) ADMIN (TOUCH THE GEAR)
-------------------------
Touch the gear prim (not the screen) to open menus.

- Object owner: edit Local (this parlor) boards — clear, remove a player, or set a score. Network: refresh cache only (no Network writes).
- Everyone else: no admin menu.

Set-score format in the text box:

    Name|score
    or
    uuid|Name|score

Admin set/remove bypasses the normal "keep higher only" rule.


7) AFTER YOU SELL OR TRANSFER
-----------------------------
The new object owner can use the gear for Local parlor boards. Network boards still follow Experience rules for that Experience.


8) QUICK TROUBLESHOOTING
------------------------
Blank screen .......... Allow Experience; whitelist feudalism-dev.github.io; enable Media; reset scripts if needed.
No new scores ......... Scoreboard more than ~100 m from the table; table missing scores script; match not finished yet.
Wrong game list ....... Use the Canasta / Hand & Foot tabs. Samba and Bolivia are Coming soon.
Network empty ......... Parcel must allow the Experience; Local parlor tabs still work without it.
Can't open admin ...... Touch the gear prim while you are the object owner.


Enjoy the parlor.
