# Ichi family variants

All variants use the **same Ichi color cards** (Red / Yellow / Green / Blue). No French suits.

| Id | Name | Summary |
|----|------|---------|
| `classic` | Classic Ichi | Match color/symbol; Skip / Reverse / +2 / Wild / +4; Call Ichi; to 500 |
| `eights` | Crazy Eights | Match color or number; **8s and Wilds** name color; to 200 |
| `dos` | Twin Piles | **Two** discard piles — play to either; same-number double play; to 200 |
| `switch` | Switch | Action ranks on Ichi colors; **2s stack** draws; to 200 |
| `palace` | Palace | Hand + 3 up + 3 down; equal-or-higher; take the pile if stuck; to 3 hand wins |
| `flip` | Ichi Flip | Light / dark sides; **Flip** card turns the deck; to 500 |

See also `RULES_ICHI.md` for Classic detail.
