# Phase It — rules (this build)

## Goal

Be the first player to complete all required phases for the chosen variant. When more than one player finishes in the same hand, the **lowest leftover score** wins.

| Variant | Phases | Order |
|---------|--------|--------|
| **Classic** | 1–10 | Fixed order |
| **Masters** | 1–10 | Choose any remaining phase each hand |
| **Sprint** | 1–5 | Fixed order (shorter race) |

## Deck

108 cards:

- Numbers **1–12** in four colors (Red / Yellow / Green / Blue), two of each
- **8 Wild** cards
- **4 Skip** cards

## Deal

Each player is dealt **10** cards. One upcard starts the discard. Play proceeds clockwise.

## Turn

1. **Masters only:** if you have not chosen this hand, pick one remaining phase before drawing.
2. **Draw** one card from the stock **or** take the top discard (cannot take a Skip).
3. Optionally **lay your current phase** if you have not yet this hand.
4. Optionally **hit** (add legal cards onto any phase already down — yours or opponents’).
5. **Discard** one card to end the turn. Discarding a **Skip** skips the next player.

You must draw before you discard. Going out (empty hand) ends the hand only after your phase is down.

## Phases

1. 2 sets of 3  
2. 1 set of 3 + 1 run of 4  
3. 1 set of 4 + 1 run of 4  
4. 1 run of 7  
5. 1 run of 8  
6. 1 run of 9  
7. 2 sets of 4  
8. 7 cards of one color  
9. 1 set of 5 + 1 set of 2  
10. 1 set of 5 + 1 set of 3  

**Set** — same number (wilds allowed).  
**Run** — consecutive numbers (wilds fill gaps; color not required).  
**Color** — same color (wilds allowed). Skips never count in a phase.

Completing a phase removes it from your remaining list. Classic/Sprint players move to the next phase in order. Masters players choose again next hand from whatever is left. Players who did not complete their phase keep that phase remaining (Masters may pick a different one next hand).

## Scoring

When a player goes out, everyone scores the cards left in hand:

- 1–9 → 5 points  
- 10–12 → 10 points  
- Wild / Skip → 25 points  

Lower totals are better for the eventual finishers’ tie-break.

## Stock

When the stock runs out, the discard (except the top card) is reshuffled into a new stock.
