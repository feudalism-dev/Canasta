# Phase It — Classic rules (this build)

## Goal

Be the first player to complete all **10 phases**. When more than one player finishes Phase 10 in the same hand, the **lowest leftover score** wins.

## Deck

108 cards:

- Numbers **1–12** in four colors (Red / Yellow / Green / Blue), two of each
- **8 Wild** cards
- **4 Skip** cards

## Deal

Each player is dealt **10** cards. One upcard starts the discard. Play proceeds clockwise.

## Turn

1. **Draw** one card from the stock **or** take the top discard (cannot take a Skip).
2. Optionally **lay your current phase** if you have not yet this hand.
3. Optionally **hit** (add legal cards onto any phase already down — yours or opponents’).
4. **Discard** one card to end the turn. Discarding a **Skip** skips the next player.

You must draw before you discard. Going out (empty hand) ends the hand only after your phase is down.

## Phases (Classic)

1. 2 sets of 3  
2. 1 set of 3 + 1 run of 4  
3. 1 set of 4 + 1 run of 4  
4. 1 run of 7  
5. 1 run of 8  
6. 1 run of 9  
7. 2 sets of 4  
8. 7 cards of one color  
9. 1 set of 5 + 1 set of 2  
10. 1 set of 5 + 1 set of 3  

**Set** — same number (wilds allowed).  
**Run** — consecutive numbers (wilds fill gaps; color not required).  
**Color** — same color (wilds allowed). Skips never count in a phase.

Completing a phase advances you one step for the next hand. Players who did not complete their phase stay on the same phase.

## Scoring

When a player goes out, everyone scores the cards left in hand:

- 1–9 → 5 points  
- 10–12 → 10 points  
- Wild / Skip → 25 points  

Lower totals are better for the eventual Phase 10 tie-break.

## Stock

When the stock runs out, the discard (except the top card) is reshuffled into a new stock.
